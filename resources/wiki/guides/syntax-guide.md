知識庫的條目使用 Markdown 撰寫，再加上幾個知識庫專用的語法。這份說明列出所有可以使用的寫法；沒有列在這裡的語法（例如 HTML 標籤）都不會顯示。

[[toc]]

## 基本格式

```markdown
## 二級標題

### 三級標題

一般段落。空一行就是新的段落。

**粗體**、_斜體_、~~刪除線~~、==螢光標記==、`程式碼或指令`

- 項目清單
- 第二項
  - 縮排兩格是子項目

1. 編號清單
2. 第二步

> 引用文字

[連結文字](https://www.nou.edu.tw/)

---
```

- 不要使用一級標題（`#`），條目標題已經是一級標題，寫了也會被改成二級標題。
- 二到四級標題會自動加上錨點，可以用 `[[slug#標題文字|顯示文字]]` 連到某一段。
- `[[toc]]` 單獨一行時，會在該處顯示本條目的目錄。
- 外部連結會在新分頁開啟。

## 表格

```markdown
| 項目 | 期中考         | 期末考         |
| ---- | -------------- | -------------- |
| 日期 | 11/7（六）     | 1/9（六）      |
| 地點 | 各學習指導中心 | 各學習指導中心 |
```

## 內部連結

連到其他條目時，用兩層中括號包住對方的**網址代稱（slug）**：

```markdown
詳見[[nou-exams-info]]。
報名前請先確認[[credit-transfer|學分抵免]]的規定。
考試時間請看[[nou-exams-info#期中考|期中考的說明]]。
```

- `[[slug]]`：顯示對方條目目前的標題。
- `[[slug|顯示文字]]`：顯示你指定的文字。
- `[[slug#段落標題|顯示文字]]`：連到對方條目的某一段。
- 連到還不存在的條目時，連結會顯示成紅色，點下去可以提議建立這個條目。這時請一定要寫顯示文字，否則讀者只會看到英文代稱。
- 中括號裡只能放英文代稱。`[[空大考試]]` 不是連結，會原樣顯示。

## 註腳：引用來源

事實資料的來源用註腳標註。在句子後面寫 `[^編號]`，再在條目最後寫出來源：

```markdown
115 學年度上學期的期中考在 11 月 7、8 日舉行。[^1]
考試採紙筆測驗，須到指定考場應考。[^2]

[^1]: [115 學年度行事曆](https://www.nou.edu.tw/)，國立空中大學教務處。

[^2]: [考試須知](https://www.nou.edu.tw/)，國立空中大學。
```

- 所有註腳會自動整理成條目最後的「參考資料」，不需要自己寫這個標題。
- 編號只是代號，系統會依出現順序重新編號。同一個來源可以重複引用同一個編號。
- 註腳內容寫明來源名稱、發布單位，並附上連結。

## 提示框

```markdown
> [!TIP] 買書小撇步
> 教科書可以在校內書局、線上書城或二手社團購買。

:::warning 繳費期限
逾期未繳費視同放棄選課。
:::
```

可用的類型：`note`（補充說明）、`tip`（小撇步）、`important`（重要）、`warning`（注意）、`caution`（當心）、`money`（費用）、`time`（時程）、`exam`（考試）、`experience`（學長姐經驗談）、`mistake`（常見錯誤）。標題可以省略，會使用預設文字。個人經驗請放在 `experience` 裡。

## 步驟

```markdown
:::steps 註冊後的四個步驟

1. 收到學生證與課程資料
2. 上網完成選課確認
3. 購買或借閱教科書
4. 登入數位學習平台
   :::
```

## 常見問題

```markdown
:::faq

### 沒有高中學歷可以讀空大嗎？

可以，年滿 18 歲即可就讀選修生。

### 一定要到校上課嗎？

不一定，多數課程有視訊面授。
:::
```

每個三級標題是一個問題，下方是答案。寫成 `:::faq open` 會預設展開第一題。

## 分頁

```markdown
::::tabs
:::tab iPhone / iPad
iOS 的操作方式。
:::
:::tab Android
Android 的操作方式。
:::
::::
```

外層的冒號要比內層多，四個冒號包住三個冒號。

## 時間軸

```markdown
:::timeline

- **8 月**：註冊選課開始
- **9 月**：開學、第一次面授
- **11 月**：期中考
  :::
```

## 檢查清單

```markdown
:::checklist

- [ ] 確認選課清單
- [ ] 繳交學雜費
- [ ] 登入數位學習平台
      :::
```

讀者勾選的項目會記在自己的瀏覽器裡。

## 倒數計時

```markdown
:::countdown
**期中考**: 2026-11-07 ~ 2026-11-08
**開學日**: 2026-09-14
:::
```

每一行是一個倒數，格式是「粗體名稱、冒號、日期」，日期寫成 `YYYY-MM-DD`，期間用 `~` 連接。

## 卡片連結

```markdown
:::cards

- [[nou-exams-info|考試怎麼考？]] — 考場、時間與注意事項

  :::
```

## 重點摘要

```markdown
:::summary
三句話講完這個條目最重要的事。
:::
```

## YouTube 影片

把 YouTube「分享 → 嵌入」提供的 `<iframe>` 程式碼單獨貼成一段即可，系統只保留影片代碼並改用隱私加強模式播放。其他網站的嵌入碼都會被移除。

## 不能使用的語法

- HTML 標籤（`<div>`、`<img>`、`<br>` 等）一律移除，YouTube 嵌入碼是唯一的例外。
- 一級標題（`#`）。
- 圖片目前只能引用站內已有的圖片。
